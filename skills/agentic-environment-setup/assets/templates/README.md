# Optional templates

Adapt these only when the project lacks an equivalent. Bracketed fields are
authoring placeholders, not facts or commands. Replace them using inspected
project evidence and remove unused sections before delivery.

- [AGENTS.md](AGENTS.md): compact project map. Merge useful content into existing
  instructions; never overwrite them wholesale.
- [task-record.md](task-record.md): objective and handoff for work spanning sessions.
- [audit-report.md](audit-report.md): evidence and ranked recommendations.

These files are output material, not instructions for maintaining Captain's Kit.
